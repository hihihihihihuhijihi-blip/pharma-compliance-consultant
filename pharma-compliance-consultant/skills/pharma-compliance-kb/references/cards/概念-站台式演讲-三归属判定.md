# 站台式演讲 · 三归属判定与两场景管控

- 类型：概念判定（口径对照）
- 来源：《讲者用的，是谁的 PPT？——站台式演讲的风险识别与管理》（公众号推文）；国家卫健委等 14 部门《2024 年纠正医药购销领域和医疗服务中不正之风工作要点》；杨市监案处字〔2017〕第 100201610082 号；恩施市监处罚〔2024〕245 号；沪工商检处字〔2017〕第 320201610056 号
- 核验状态：本次维护未核对法律及案例原件；场景归纳可作分析提示，具体条号、金额、引语与时效须另行核验。
- 时间：2024年相关文件及历史案例线索；发布时间、术语沿革和当前适用性须核验
- 关键词：站台式讲课、站台式演讲、讲课费、企业课件、推广性质、学协会、借台、变相利益输送、商业贿赂

> 核验门槛：本卡历史版本包含未核验的术语时效、条号、案例金额及推断。以下均为检索和分析线索；不能直接作为当前监管认定或放行依据。

## 要点

1. **定义**：讲者以专家身份登台，讲的不是自己的学术判断，而是企业准备的、以推广为目的的课件。
2. **分析三个归属**：内容归属 / 身份归属 / 场合归属。三归属是分析工具，不是法律构成要件；不能据此排除其他违规风险。
3. **术语线索**：检索2024年纠风工作要点中的“站台式讲课”及相关地方文件。是否首次出现、其他年度是否使用及当前政策口径，须逐份核对，不从历史卡片推定。
4. **常被误读**：该纠风文件是医疗端文件（落点在医院与医务人员，依据《医师法》），不等于与企业无关——**医疗端限制可能提示企业端风险，但不能直接推出企业商业贿赂认定**，企业侧对应商业贿赂那条线。
5. **两个场景，两套管法**：学协会主办 → 管"借台"；企业自办 → 管"内容"。
6. **审查范围**：结合真实内容、讲者服务、主办关系、对价及利益关联核查；不凭三归属判断、付款形式或产品出现单独定案。

## 场景分析（三归属，不是放行或违法标准）

| 归属 | 参考控制 | 需进一步核查的信号 |
|---|---|---|
| 内容归属 | 讲者自己的学术判断 | 企业准备的推广课件 |
| 身份归属 | 以专业身份独立发声 | 替企业念稿、做背书 |
| 场合归属 | 议程独立、经学术审查 | 企业内容直接上议程 |

**辅助观察信号（不能单独定性）**：

1. 把 PPT 上的企业 logo 挡住，再看这场演讲——观察是否存在产品推广目的，再核查内容与适用规范。
2. 问讲者一个跟 PPT 无关的问题——不能据一次回答判断真实服务，需结合准备、交付和内容核实。
3. 看这笔钱谁付的、付的是什么——企业直接付给讲者个人、金额又与实际内容不成比例，应进一步核查真实服务和合理对价。

## 两场景控制建议（需结合实际职责与协议）

| | 学协会主办（管"借台"） | 企业自办（管"内容"） |
|---|---|---|
| 讲者遴选 | 按主办关系、捐赠或赞助性质及适用要求核查选择权；区分受资助者与服务者 | 核实选聘理由、真实任务和利益关联，不只看邀请部门 |
| 课件 | 纳入学协会学术审查，标注资料来源 | 走企业内部审批，以核准说明书为准 |
| 利益披露 | 讲者会前披露与企业合作关系 | 讲者名单与课件版本一起留痕 |
| 费用路径 | 明确协议支付方和最终受益人；具体路径依适用规范核定 | 有标准、与时长匹配、代扣个税、有凭证 |
| 合作与回报 | 先区分捐赠、赞助与委托服务；按真实性质、协议及已核验要求审查用途或权益，不默认存在商业回报 | 核实内容、费用和机构要求，避免安排无真实业务关系的旅游娱乐 |

> 支付渠道是审查因素；由学协会支付不自动合规，企业直接支付也不单独决定违法。

## 待核验的法律线索

以下为历史卡片内容，仅保留供核验；不是本轮确认的法律结论。尤其不得将同期采购、企业课件、个人收款单独当作违法充分条件。

- **内容**：《药品管理法》第九十条、《广告法》第十六条——不得利用专家、学者、医师等名义或形象作推荐、证明；内容以核准说明书为准
- **身份**：《医药代表管理办法》第二十一条（仅授权传递信息、协助合理用药、收集临床反馈三项）、第二十四条（禁止夸大或误导疗效、隐匿已知不良反应）；第二十条（院内活动须机构同意）
- **场合与赞助**：《医药企业防范商业贿赂风险合规指引》第二十八条（捐赠不得指定具体受益人）、第三十一条（禁止假借赞助影响处方与采购）
- **资金**：核验药品管理及反商业贿赂规范中的主体、行为和利益关联要求。学术支持与采购在时间或主体上重合是核查线索，不能单独作为商业贿赂认定；历史卡片的条号与概括不得直接引用。
