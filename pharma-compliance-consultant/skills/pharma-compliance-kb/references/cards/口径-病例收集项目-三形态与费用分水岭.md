# 病例收集 / 病例征集项目 · 三形态与费用分水岭

- 类型：口径对照
- 来源：由《医药合规判断准则》在此场景的应用归纳；本卡未引用具体原件，资料库可用性以当次实际查询为准
- 核验状态：本次维护未核对法律及案例原件；场景归纳可作分析提示，具体条号、金额、引语与时效须另行核验。
- 时间：2026-10
- 关键词：病例收集、病例征集、病例费、真实世界研究、RWS、上市后研究、IIT、讲课费、商业贿赂、HCP互动、人遗资源、个人信息保护

## 要点

1. **费用分水岭**：审查付款对应真实研究工作、学术创作或专业服务，还是产品使用、处方或采购激励。按例研究预算、按篇稿酬并非天然违规，也非自动合规；核验真实需求、工作量、交付质量、合理定价与利益关联。
2. **组合信号**：销售参与征集、按病例件数向医生个人付款、限定本公司产品或选择目标医生等，是需要进一步核查的风险信号。不得据此直接认定商业贿赂，也不能靠合同、发票和截图代替实质审查。
3. **先还原控制关系**：确认APP、公众号及征稿平台的运营与实际控制方，企业是资助、委托还是直接运营；谁选医生、定题、评审、付款、发布。独立出版需求与借平台付款必须分别判断。
4. **有前提的业务路径**：
   - **医学研究型**：确认真实科学问题、研究方案及适用的伦理和机构管理要求；费用对应方案内工作，支付渠道符合协议和机构要求。不能把推广项目改名为研究。
   - **学术征稿型**：仅在有真实出版需求及可独立验收的创作时适用。可建议医学或独立编辑团队负责选题和评审，按合理标准支付合格稿件的稿酬，与处方采购脱钩；这些是控制建议，不是未核验的通用部门禁令。区分作者稿酬、评审劳务与赛事奖金，不混为一项。
   - **数据与传播侧**：去标识化不等于匿名化；可识别的医疗健康信息按适用法律核实处理基础、敏感信息及公开披露要求。皮肤科照片检查脸部、纹身、特殊体征和组合信息。患者授权、作者版权授权、机构要求分别核查；按实际数据处理关系安排平台协议，人遗和跨境事项按触发条件另审。
5. **支付穿透与总额审查**：建议合并查看同一医生病例稿酬、讲课费、顾问费等的总额、频次和重复交付；限额依据企业制度或适用且已核验的规范，不宣称存在统一法定年度上限。第三方付款核验最终收款人和实际工作；已有真实履约款项逐笔处理，不一律停付。
6. **真实性与发布验收**：由有权限的机构或人员在最小必要范围核验病例来源、创作和交付，优先采用机构内核验及必要确认材料，不为核验扩大原始患者数据接触。APP和公众号分别审查受众、内容及广告属性，医生身份验证不自动豁免互联网广告限制；适用时设置药物警戒信息转交机制。
7. **处置要有边界**：根据已知风险明确暂缓新增征集、承诺、发布或具体异常付款，并列恢复条件；如实区分风险倾向、审批意见和违法认定。实际目的若是奖励产品使用，不能以改部门、改名称或增设评审作为放行理由。

## 适用边界

- 适用于药品、器械企业在境内开展的病例收集 / 病例征集 / 病例大赛 / 典型病例分享类项目，不适用于患者援助（PAP）的独立合规审查（另立口径）。
- 是否构成商业贿赂须个案判断，与支付对象身份、金额、对价关系、主观明知、处方因果链长短相关；**公立医院医师是否被认定为国家工作人员，司法实践存在不同认定**，涉刑判断必须个案评估并交由执业律师出具意见。
- 《反不正当竞争法》业务贿赂条款条号以现行有效文本为准（2025 年修订版已发布，引用前复核条号）；库中案例具有时效性，处罚时间早于现行法的仅作参考。
- 本卡为判断骨架，不替代对具体项目合同、方案、伦理批件、HCP 台账的实质审查。
