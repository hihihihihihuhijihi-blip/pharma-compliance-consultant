# 安装与知识查询

公开包包括判断准则、专题卡片、工作流程、已登记资料元数据索引和固定接口查询脚本，不包含原件、检索缓存或私有 MCP 配置。

- Claude Code：完整目录放入 `~/.claude/skills/` 或项目 `.claude/skills/`；启动新会话，直接输入 `/pharma-compliance-consultant`。
- Cursor：完整目录放入 `~/.cursor/skills/` 或项目 `.cursor/skills/`；在对话中输入 `/`，选择 `pharma-compliance-consultant`。个人安装显示为 `User skill`，项目安装确认选择项目来源。
- 豆包工作：技能管理 → 上传完整 ZIP；在对话中输入 `/`，搜索 `pharma-compliance-consultant`，选择「个人」中的 `Pharma Compliance Consultant`。
- Codex 桌面端：完整目录放入 `~/.agents/skills/` 或项目 `.agents/skills/`；输入 `/`，搜索 `pharma-compliance-consultant` 并选择对应公开版技能。Codex CLI／IDE 使用 `/skills` 后选择，或 `$pharma-compliance-consultant`。

统一技能标识为 `pharma-compliance-consultant`，原生 `/` 调用是交付验收条件：选中技能、实际加载公开版入口，再完成知识查询。已有同名旧技能、命令或链接时，应更新其入口到公开版并确认来源，避免误选旧版。只看到名称或手动读取文件不算 `/` 验收通过。

本包只注册根目录的一个技能入口。知识库使用说明、判断准则、卡片和索引均为内部参考资料，不另外安装 `pharma-compliance-kb` 技能或同名快捷提示。

无需注册 MCP；能执行 Python 标准库脚本或读取 HTTPS JSON 的平台可使用固定知识接口，具体调用见根 SKILL.md「公开知识查询」。平台没有脚本或联网能力时按准则与卡片回答，如实说明核验边界。

原件保持私有；公开接口仅提供检索结果和相关文字摘录，不提供原件下载。仅发送通用检索词，禁止上传合同、病例、患者信息或内部数据。

最新完整包：[下载 ZIP](https://skills.compliances.cc/pharma-compliance-consultant.zip)。[版本与包哈希](https://skills.compliances.cc/version.json)。原件资料更新由查询接口实时读取；判断规则、卡片或技能更新后须下载新版并重新导入，已安装副本不会自动替换。

仅调用技能而未说明任务时，先显示交互式任务选项，等待用户真实选择后执行。用户已说明任务或明确要求继续时，直接推进。

业务信息不足时，采用渐进提问：每轮一个独立判断点，优先给简短选项，收到真实答复后再决定下一问；不把整套事实清单塞进一个开放题。

仅在用户明确要求连接验收时，可通过上述 `/` 入口选中技能后提交测试：检索「医药代表」，返回命中文件名、版本、相关摘录、引用与核验边界。这是验收示例，不是默认启动任务。验收应实际测试状态、检索、摘录及相关卡片加载；结构通过不等于端到端接入已验收。
